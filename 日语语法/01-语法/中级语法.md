  # 001 ～とき・～直後に
  1. [[N2 001-1～際（に）]] 
     **正式版「～とき」 + 关键时机 + 书面表达**
  2. [[N2 001-2～に際して・～に当たって]] 
		👉 に際して  
		= **重要时刻（人生节点）**
		👉 に当たって  
		= **做某事前（准备阶段）**
  3. [[N2 001-3～たとたん（に）]]
		👉 ～たとたん（に）＝  
		**刚一……就……（瞬间 + 突发 + 非人为）**
  4. [[N2 001-4～（か）と思うと・～（か）と思ったら]]
		👉 ～（か）と思うと／と思ったら ＝  
		**刚一……就……（变化快 + 出乎意料 + 状态切换）**
  5. [[N2 001-5～か～ないかのうちに]]
	    **刚要……还没来得及……就……（极限瞬间）**

#    015 もしそうなら・たとえそうでも
  1. [[N2 015-1～としたら・～とすれば、～とすると、～となったら、～となれば、～となると]]

| 语法       | 中文     | 核心     |
| ---------- | -------- | -------- |
| としたら   | 如果     | 假设     |
| とすれば   | 如果说   | 推理     |
| とすると   | 那么     | 顺推     |
| となったら | 一旦到了 | 关键情况 |
| となれば   | 既然如此 | 判断     |
| となると   | 一涉及   | 情况变化 |
  2. [[N2 015-2～ものなら]]

| 语法    | 一句话       |
| ----- | --------- |
| ものだから | 因为……嘛（辩解） |
| もので   | 因为……（郑重）  |
| もの    | 因为嘛！（撒娇）  |
 
  3. [[N2 015-3～（よ）うものなら]]

  5. [[N2 015-5～を抜きにしては]]
		👉 ～を抜きにしては ＝

| 语法   | 一句话      |
